Momentary Press (Power Button)
Sends a short pulse on the server power button. Powers ON if off, or initiates graceful ACPI shutdown in the OS.
Power On (Turn On)
Directly sends hardware power-on command to start the motherboard and boot the system.
Graceful Power Off
Signals the operating system to shut down cleanly and power down the chassis.
System Reset (Warm Reboot)
Triggers hardware reset line on the system board. Recommended if OS has hung or during troubleshooting.
Cold Boot (Power Cycle)
Instantly cuts DC power to the motherboard and automatically powers the server back on.
Force Power Off (Hold 5s)
Simulates holding the power button for 5 seconds. Immediately cuts power. Unsaved data may be lost.
